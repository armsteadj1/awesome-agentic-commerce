# Awesome Agentic Commerce

A public, capability-first tracker for agentic commerce: PSPs, processors, consumer wallets, agent wallets, agent cards, payment protocols, gateways, policy/identity layers, API marketplaces, and settlement rails.

This is intentionally *not* an adoption or volume leaderboard yet. The market is too early and too noisy. Treat this as a map of possible companies/products to verify, not proof that each is live or production-ready.

## Scope

This list includes public candidates from ecosystem maps, public product/docs pages, mirrored X/Twitter market-map snippets, AgentCash docs, and processor/wallet research notes.

Columns are capability-first:

- `Lane`: where the product sits in the stack
- `Payment methods`: the credential, funding source, or settlement method exposed to the agent/user
- `Rails / protocols`: known agentic-commerce protocols only; use `TBD` when unknown
- `Surface`: where adoption shows up for merchants, agents, developers, or consumers
- `Open questions`: what still needs verification
