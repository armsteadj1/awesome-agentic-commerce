# Awesome Agentic Commerce

A curated tracker for companies building the agentic commerce stack — wallets, processors, payment protocols, routing layers, policy infrastructure, and identity systems that enable AI agents to transact.

This is not an adoption leaderboard. The market is early. Treat this as a map of companies and products to watch, not proof that each is live or production-ready.

## Scope

Tracked categories:

- **Agent Wallets** — custody, key management, and wallet infrastructure for autonomous agents
- **Consumer Wallets** — payment surfaces consumers use today that agents must interact with
- **PSP / Processor** — payment processors and acquirers
- **Protocol / Payment Rail** — agent-native payment protocols (x402, MPP, AP2, L402)
- **Routing / Abstraction** — payment orchestration, fiat-crypto bridging, and on/off-ramps
- **Policy / Spend Control** — spend limits, credential delegation, tokenization, card issuing, and governance
- **Identity / Trust** — agent identity, reputation, and verification
- **Agent Marketplace** — platforms where agents discover and pay for services
- **Commerce Platform** — platforms enabling merchants to accept agent-initiated purchases

*Agent capability*

- `Wallet Injection` - inject or present an agent-capable wallet/credential into a checkout or merchant acceptance flow
- `Credential Delegation` - delegate user-approved payment credentials to an agent without exposing raw credentials
- `Card Issuing` - issue a card or virtual card for agent spend
- `Agent Wallet Funding` - fund, custody, or manage spend from an agent wallet/balance
- `API Metering` - meter and charge for API/tool usage
- `Embedded Checkout` - complete purchase in an agent/chat/app context through merchant checkout primitives
- `Checkout Automation` - browser or checkout injection into existing merchant checkout
- `Agent Authentication` - prove the agent is legitimate / authorized
- `Settlement / Routing` - route, settle, swap, bridge, or orchestrate funds
